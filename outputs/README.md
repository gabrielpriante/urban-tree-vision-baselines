# Outputs

This directory contains generated experiment results.

Model inference may produce:

- Raw prediction tables
- Segmentation masks
- Bounding-box predictions
- Annotated imagery
- Summary statistics
- Run metadata
- Diagnostic information

Generated outputs are excluded from Git version control by default because they can be large and can always be recreated from the documented inputs, configuration, model version, and source code.

Selected finalized results may later be added to the repository deliberately when they are useful for documentation, validation, or publication.
